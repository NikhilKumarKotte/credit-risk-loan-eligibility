2) DATASET GENERATION (Synthetic but realistic)
-----------------------------------------------
The dataset is created using controlled statistical distributions:
- Income correlates with age and employment type.
- Expenses are a fraction of income.
- Defaults follow a probabilistic log-odds model.

Default probability uses a logistic function:

  log_odds =  0
           +  1 * DTI
           +  2 * Previous_Defaults
           +  3 * Late_Payments
           -  4 * Credit_History_Length
           -  5 * Income
           +  6 * Outstanding_Loan_Amount
           -  7 * Savings_Balance
           +  8 * Employment_Status
           + noise

  P(default) = 1 / (1 + exp(-log_odds))

Then Loan_Default ~ Bernoulli(P(default))

4) FEATURE ENGINEERING FORMULAS
-------------------------------
- Credit Utilisation Ratio:
  Outstanding_Loan_Amount / (Income/12 * Loan_Term)

- Spending Ratio:
  Monthly_Expenses / (Income/12)

- Repayment Stability:
  1 / (1 + 0.5*Late_Payments + 1.5*Previous_Defaults)

- Savings Coverage Months:
  Savings_Balance / Monthly_Expenses

- Loan Burden Ratio:
  EMI / (Income/12)

- Financial Stress Index:
  0.4*DTI + 0.3*Spending_Ratio + 0.3*Loan_Burden_Ratio

- Credit Experience Score:
  0.7*Credit_History_Length + 0.3*Number_of_Credit_Cards

- Income to Loan Ratio:
  Income / Loan_Amount


5) MODEL TRAINING: HOW EACH MODEL LEARNS (WITH WORKED EXAMPLES)
---------------------------------------------------------------
A) LOGISTIC REGRESSION

Core formula:
  z = w x + b
  p = 1 / (1 + exp(-z))

Loss (log-loss):
  L = - (y*log(p) + (1-y)*log(1-p))

Example 1:
Assume only 3 features:
  x = [DTI=0.90, LatePayments=1, Income=65000]
  w = [1.2, 0.8, -0.00002], b = -1.0

Compute:
  z = 1.2*0.9 + 0.8*1 - 0.00002*65000 - 1.0
    = 1.08 + 0.8 - 1.3 - 1.0
    = -0.42

  p = 1 / (1 + exp(0.42))
    = 0.396

Prediction = 39.6% default probability.

Example 2:
  x = [DTI=0.40, LatePayments=0, Income=100000]
  z = 1.2*0.40 + 0 - 0.00002*100000 - 1.0
    = 0.48 - 2.0 - 1.0
    = -2.52
  p = 1/(1+exp(2.52)) = 0.074

Prediction = 7.4% default probability.


B) RANDOM FOREST

Random Forest is an ensemble of decision trees.
Each tree learns rules by splitting data to reduce impurity.

Sample decision tree (simplified):

          [DTI > 0.75?]
            /        \
         Yes          No
         /             \
 [LatePayments > 1?]  [Income > 70000?]
     /     \             /        \
   Yes     No         Yes         No
  Default  Default?   No Default   Default?

Explanation:
- If DTI is high and late payments are high, default risk rises.
- If DTI is low and income is high, default risk is low.

Worked example:
Applicant:
  DTI = 0.90, LatePayments = 2, Income = 55000

Tree path:
  DTI > 0.75 = Yes
  LatePayments > 1 = Yes
  => Default (1)

Forest prediction:
Suppose 5 trees output: [1,1,0,1,0]
Majority vote = 1
Probability = 3/5 = 0.60


C) XGBOOST (Gradient Boosted Trees)

XGBoost builds trees sequentially.
Each new tree focuses on reducing residual error.

Sample boosted tree (simplified):

Tree 1:
  if DTI > 0.7 -> +0.40
  else -> -0.10

Tree 2:
  if LatePayments > 1 -> +0.25
  else -> -0.05

Tree 3:
  if Income > 80000 -> -0.30
  else -> +0.05

Prediction score = sum of tree outputs
Then apply sigmoid:
  p = 1 / (1 + exp(-score))

Worked example:
Applicant:
  DTI=0.85, LatePayments=2, Income=60000

Tree1: DTI>0.7 => +0.40
Tree2: LatePayments>1 => +0.25
Tree3: Income>80000? No => +0.05
Total score = 0.70
p = 1/(1+exp(-0.70)) = 0.668

Prediction = 66.8% default probability.

7) PREDICTION & RISK SCORING (Mathematical Proof)
-------------------------------------------------
Default probability p from model:

Credit score:
  Score = 300 + (1 - p) * 600

Example:
If p = 0.823
Score = 300 + (1 - 0.823)*600
      = 300 + 106.2
      = 406

Risk tiers:
- 300 499: HIGH RISK
- 500 699: MEDIUM RISK
- 700 900: LOW RISK


8) ELIGIBILITY & EMI CALCULATION
--------------------------------
Monthly income = Annual income / 12
DTI cap = 0.40 * Monthly income
EMI capacity = max(0, DTI cap - Monthly expenses)

EMI formula:
  EMI = P * r * (1+r)^n / ((1+r)^n - 1)

Where:
- P = loan principal
- r = monthly interest rate = annual_rate / 12 / 100
- n = number of months

To estimate maximum loan, EMI formula is rearranged:
  P = EMI * ((1+r)^n - 1) / (r*(1+r)^n)
